# Kerf 2D

A lightweight, browser-based precision 2D CAD tool for design & technology and laser cutting, modelled on the behaviour of TechSoft 2D Design V3. It is a clean-room implementation: no TechSoft code, icons, help text or drawings are used.

## Commands
```
npm install
npm run dev              # local development server
npm test                 # automated tests (geometry + full workflow self-test)
npm run typecheck        # TypeScript checks
npm run build            # one self-contained, offline HTML file → dist/index.html
npm run build:artifact   # same, packaged for publishing as a page → dist/kerf-artifact.html
```

## Architecture
```
src/
  geometry/   pure maths, no UI — candidate for a Rust/WebAssembly kernel later
    vec.ts        points, angles, number cleaning, unit parsing (2cm, 1in…)
    entity.ts     flattening, primitives, intersections, distances, snap points, bounding boxes
    affine.ts     move / rotate / mirror / scale / squash (exact for circles, arcs, ellipses)
    offset.ts     contour/offset engine (Clipper), chaining touching pieces, single-edge offsets
    region.ts     boundary finder: the enclosed area around a point, even with crossing lines
    trim.ts       Delete Part (whole path or segment by segment)
    dims.ts       dimension geometry
  model/      document types, colours/pages, document store with undo/redo
  snap/       Attach snapping (end, mid, centre, quadrant, intersection, nearest, perpendicular, tangent) + locks
  editor/     Editor (selection, view, input routing, transforms) and the Tool contract
  tools/      one file per tool group; registry in tools/index.ts
  render/     canvas renderer
  io/         SVG and DXF import/export, zip helper
  ui/         browser shell: toolbox, option strips, panels, status bar, files
  selftest.ts accuracy checks run in-app (Accuracy tab) and in `npm test`
tests/        Vitest suites
```

### Adding a tool
Most drawing tools are "locate N points, then make something". For example:
```ts
export const myTool = pointTool({
  id: 'slot', label: 'Slot', key: 'K', icon: '<path d="…"/>', group: 1, need: 2,
  prompts: ['Locate first centre', 'Locate second centre'],
  options: [{ key: 'slotW', label: 'Width', type: 'number', unit: 'mm' }],
  make(ed, [a, b]) { ed.store.change(() => ed.store.add(/* shape */)); },
  preview(ed, [a], cur, o) { o.ghost(/* preview shape */); o.label('…'); },
});
```
Register it in `src/tools/index.ts`. The toolbox button, keyboard shortcut and option strip appear automatically, and snapping, typed coordinates, drag-to-draw, Backspace (remove last point), undo and export all work without extra code.

Fixed: Elements, Box maker and Trace windows ran off the bottom of short screens and could not scroll.
- **v0.9**: **Living hinge** (Make ▾ → Living hinge…). *Wrap a shape*: exact strip length along the neutral line (shape offset by t/2), slits only where it bends, spacing fitted to each curve, ★ Recommend (spacing, slits across, bridge from material, thickness, kerf and the tightest bend), bend check per column (green / orange / red), sharp-corner finder with "Round the corners" (exact fillets), strip split at flat spots to fit the bed, base/lid joints: plain, shelf (two layers) or slots and tabs (tabs at the flattest spots, slots widened for the curve), engraved guide lines, cut length and laser-time estimate. *Inside a shape*: fills a closed shape with slits kept clear of its edge. *Test strips*: four strips at increasing spacing to calibrate a material. Help topic "Living hinge".
- **v0.9.1**: Trim fix — trimming the far end of a path that had already been trimmed open no longer adds a straight line back to its start (open paths no longer "wrap round"). *Segment by segment* now removes just that piece and keeps the rest of the path as one path (it used to break the whole path into separate lines). Living hinge: new joint **Tabs on the shape, through the strip** — the base (or lid) is your shape with tabs reaching out to the strip's outside face, and the strip gets matching slots ("Slots up from the edge"; 0 = open notches).
- **v0.10**: **Bend to a profile** (Make ▾ → Bend to a profile…): draw or pick a side-view curve (or use one drawn beside the shape) and get a flat copy with living-hinge slits that bends to it. Side-view editor: drag points forward/back, click the line to add, double-click to remove; points stop where the wood can bend no tighter; presets (straight, arc, S-curve, wave, slope back, tip folds forward, streamline) and depth %. *Keep how it looks* (drawing = view from the front, flat copy lengthened by the curve's arc length) or *Keep its length* (drawing = flat piece; can curl). Slits only where it bends, spacing fitted to each part of the curve, kept clear of edges and holes (eyes etc.), bend check per column, narrow-tip warning; optional former(s) cut to the profile with engraved glue lines; laser-time estimate.
